❷ Project Overview (Detailed)

🧠 Goal: Predict when to change a patient’s posture to prevent pressure ulcers.
📡 How: Use temperature sensors (DS18B20, DHT22) with ESP32 to collect data, send via MQTT to Firebase, and analyze with ML models.
📱 Interface: iOS app shows real-time posture status and alerts.
