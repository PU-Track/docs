🩺 PU-Track: Smart System for Predicting Postural Change Intervals to Prevent Pressure Ulcers

PU-Track is a smart healthcare system designed to prevent pressure ulcers by predicting patient posture change intervals using IoT-based temperature sensing and machine learning models.

This project was initiated to enhance both caregiving efficiency and patient safety in clinical environments.

❷ Project Overview (Detailed)

🧠 Goal: Predict when to change a patient’s posture to prevent pressure ulcers.
📡 How: Use temperature sensors (DS18B20, DHT22) with ESP32 to collect data, send via MQTT to Firebase, and analyze with ML models.
📱 Interface: iOS app shows real-time posture status and alerts.
